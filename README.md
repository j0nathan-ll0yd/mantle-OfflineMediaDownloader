# Media Downloader

[![Built with Mantle](https://img.shields.io/badge/built%20with-Mantle-blue)](../mantle)

A serverless YouTube media downloader with a companion [iOS App](https://github.com/j0nathan-ll0yd/ios-OfflineMediaDownloader). Built on the [Mantle framework](../mantle) and deployed to AWS.

## Quick Start

```bash
# Install dependencies
pnpm install

# Build all Lambda functions (Docker-free: skips the StartFileUpload container image)
pnpm run build:ci

# Deploy to staging
npx mantle deploy --stage staging

# Deploy to production
npx mantle deploy --stage production
```

Routine builds (CI and local `build:ci`) are Docker-free — `StartFileUpload`
(`packageType: 'container'`) is referenced by a pinned ECR image digest
(`docker/start-file-upload.pin.json`) instead of being rebuilt on every change. Refresh
that image with `bin/refresh-download-image.sh` (operator-run on a host with Docker) when
`docker/Dockerfile.download`, `layers/**`, or the `StartFileUpload` bundle change — see
`docker/start-file-upload.pin.README.md`.

## Architecture

18 Lambda functions organized across three categories:

- **API** — REST endpoints routed via API Gateway (file-system routing)
- **EventBridge** — Async event-driven handlers (exports, notifications)
- **Standalone** — Direct-invocation handlers (auth, webhooks)

**AWS services**: Lambda, API Gateway, Aurora DSQL, S3, SNS (APNS), SQS, EventBridge, CloudWatch

**[Architecture diagram](https://gitdiagram.com/repo/j0nathan-ll0yd/mantle-OfflineMediaDownloader)** (via GitDiagram)

## Key Features

- **Better Auth** — Apple Sign In (ID token flow) with 30-day session management
- **Aurora DSQL** — Serverless PostgreSQL with Drizzle ORM and type-safe queries
- **Media downloads** — yt-dlp + FFmpeg container Lambda, auto-updated weekly via GitHub Actions
- **Push notifications** — APNS delivery via SNS
- **Custom authorizer** — Query-based API tokens for Feedly integration
- **EventBridge** — Async event bus for decoupled exports and processing
- **SQS** — Queued media download jobs
- **Fixture capture** — Production request/response logging from CloudWatch for test generation
- **pnpm lifecycle protection** — Supply chain attack hardening

## Project Structure

```
├── bin/                   # Shell scripts (deploy checks, integration tests, utilities)
├── config/                # Tool configuration (ESLint rules, dependency-cruiser, dprint, repomix, Stryker)
├── docker/                # Dockerfiles and docker-compose files (LocalStack, test PostgreSQL, container Lambda)
├── docs/                  # Documentation, wiki, API spec, ADRs
├── graphrag/              # Knowledge graph extraction and querying
├── infra/                 # AWS infrastructure definitions (OpenTofu)
├── layers/                # yt-dlp assets (cookies, VERSION) baked into the download container
├── migrations/            # Drizzle ORM database migrations
├── permissions/           # DSQL role permissions (generated by Mantle CLI)
├── scripts/               # Development scripts (cookie extraction, scaffolding)
├── secrets/               # SOPS-encrypted environment secrets
├── src/                   # Application source code (lambdas, entities, services, types)
├── static/                # Static assets (default media files)
└── test/                  # Unit and integration tests
```
